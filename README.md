## Bottom Navigation – Jetpack Compose

I have created this Jetpack Compose demo to showcase a simple yet practical bottom navigation app using Material 3. It includes multiple screens, where each screen can navigate to a detail screen while passing data through navigation arguments.

## Features

- Jetpack Compose Navigation
- Bottom Navigation Bar with icons and labels
- Four main screens (Home, Profile, Settings, Calls)
- Navigation to Detail screen from each main screen
- Data passed to Detail screen using route arguments
- Current route-aware bottom bar with back stack support
- Shows BottomBar only on defined bottom screens
- Clean project structure with navigation handling

## Tech Stack

- Kotlin
- Jetpack Compose
- Navigation-Compose
- Material 3
- AndroidX
